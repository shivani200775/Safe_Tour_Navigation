ABOUT OUR PROJECT

What is Safe Tour Navigation?

Safe Tour Navigation is a tourist safety web application designed to help travellers explore unfamiliar places with better awareness. It provides information about tourist destinations, reported danger areas, potholes, road conditions and safety-related observations.
